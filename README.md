# C++ Functions and Recursion

A collection of C++ programming exercises covering functions, function concepts, and recursion.

## Project Structure

### 1. Function Basics
- Creating and calling functions
- Adding two numbers using functions
- Checking even and odd numbers

### 2. Function Concepts
- Finding the largest number
- Pass by value
- Pass by reference
- Function overloading
- Default arguments

### 3. Recursion
- Factorial using recursion
- Fibonacci series using recursion
- Sum of digits using recursion

### 4. Mini Project
- Menu driven calculator using functions

## Technologies
- C++
- Standard C++ Library

## How to Run

Compile any program using:

```bash
g++ filename.cpp -o program
```
